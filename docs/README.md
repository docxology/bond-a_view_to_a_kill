# Documentation

This directory is the operational rulebook for agents and developers inside
`a_view_to_a_kill` (ZORIN). Start with `agent_instructions.md`, then read
`architecture.md` before changing module boundaries and
`testing_philosophy.md` before writing tests.

The package formalizes ZORIN's scheme from *A View to a Kill* (1985) as three
deterministic models — microchip supply-chain monopoly analysis,
flood-the-mine water-ingress dynamics, and race-form cover analytics — wrapped
in a FROZEN `bond_api.MissionProvider`.
