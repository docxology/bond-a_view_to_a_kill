# Manuscript — ZORIN (A View to a Kill, 1985)

This package's manuscript formalizes Max ZORIN's scheme as deterministic
computational models:

1. Microchip supply-chain monopoly choke-point analysis.
2. Flood-the-mine water-ingress dynamics.
3. Race-form cover analytics.

All numbers flow from `config.yaml` + the pure core through
`manuscript_variables.py`. To render/regenerate, run:

```bash
uv run python scripts/z_generate_manuscript_variables.py
```

See `SYNTAX.md` for token/figure syntax and `AGENTS.md` for editing rules.
